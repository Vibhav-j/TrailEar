TrailEar

An offline bird-call companion. Walk with earbuds in and the laptop in your bag: it identifies birds locally, whispers their names, and writes a field journal when you get home. Built for the HackOctober "Touch Grass" challenge.

Instructions for the coding agent

Build this entire repository in one pass from this document. Follow these rules:

  • Create every file in the folder structure (section 5). No placeholders marked TODO in core paths (audio, classify, detect, storage, voice, llm, api).
  • Target Windows 10/11, Python 3.11. Use pathlib, no bash-only commands. Setup must run from PowerShell.
  • Everything runs locally with no network after setup. No cloud APIs, no API keys, no telemetry.
  • Every external model sits behind an abstract interface (section 6) so it can be swapped via config.yaml.
  • Ship a MockClassifier and a MockLLM so the app and tests run even if BirdNET, TensorFlow or Ollama fail to install.
  • The LLM never identifies birds. It only writes prose from rows in SQLite (section 8).
  • Run the tests at the end, fix failures, and finish with a short summary of what works and what is untested.

1. What it does and why open matters

Flow: microphone, then 3-second audio windows, then an open-weight bird classifier, then a debounce step, then SQLite and a spoken name in your earbuds. After the walk, a local LLM turns your detections into a short journal entry.

Open advantageHow TrailEar shows it
Works with no signalBirds live where there is no coverage. Everything runs offline; the demo is recorded in airplane mode.
Data stays yoursRaw audio is processed in memory and never uploaded. Optional clip saving is off by default.
Swap models freelyClassifier, LLM and TTS voice are config values. Use a bigger LLM at home and a smaller one on the trail.
Zero running costNo keys, no per-call fees, no subscription.

Licence note to include in the README: BirdNET model weights are licensed for non-commercial use. Google's Perch is a more permissive alternative and should be listed as a planned second Classifier backend.

Runtime model

  • Threads: capture thread pushes windows to a queue.Queue; a classifier worker consumes it; detections go to the manager, which fans out to storage, TTS and the WebSocket broadcaster. TTS runs on its own thread so speech never blocks classification.
  • Walk lifecycle: start_walk() creates a walk row; stop_walk() closes it and triggers journal generation.
  • Failure policy: if the classifier, TTS or LLM fails, log it, degrade (for example, text-only), and keep the walk running.

5. Module contracts

types.py

@dataclass(frozen=True)
class Window:      samples: np.ndarray; sample_rate: int; t_start: float   # seconds since walk start
@dataclass(frozen=True)
class Detection:   scientific_name: str; common_name: str; confidence: float; t: float
@dataclass
class WalkSummary: walk_id: int; started_at: str; ended_at: str; duration_s: int; species: list[dict]

Interfaces

class Classifier(ABC):
    @abstractmethod
    def classify(self, window: Window) -> list[Detection]: ...   # sorted by confidence desc

class LLM(ABC):
    @abstractmethod
    def generate(self, system: str, prompt: str, max_tokens: int = 400) -> str: ...

class TTS(ABC):
    @abstractmethod
    def speak(self, text: str) -> None: ...                      # non-blocking, queued

Behavior rules

  • capture.py: MicSource yields 3 s windows with a 1 s hop at 48 kHz mono (BirdNET native rate). FileSource reads a WAV and yields the same windows, used for tests and the demo. List input devices via python -m trailear devices.
  • birdnet.py: wraps birdnetlib; passes lat, lon and week from config; returns only detections at or above min_confidence. Load the model once.
  • manager.py: accept a detection only if confidence ≥ announce_threshold; suppress the same species for cooldown_s; require min_consecutive hits within a short span before announcing. Emit an event only for new announcements.
  • tts.py: Piper voice from models/; speaks the common name only (for example "Eurasian Hoopoe"). A NullTTS is used when disabled or when Piper is unavailable.
  • prompts.py: the journal prompt receives a JSON list of detected species with facts and counts, and must instruct: "Mention only the species provided. Do not add any other birds. If a fact is missing, leave it out." Output is 120 to 180 words, first person, calm tone.
  • Grounding check: after generation, scan the text for any known species name not in this walk's list; if found, regenerate once, then fall back to a plain template summary.

6. config.yaml

location:
  lat: 0.0              # set your own coordinates
  lon: 0.0
audio:
  device: null          # null = system default input
  sample_rate: 48000
  window_s: 3.0
  hop_s: 1.0
classifier:
  backend: birdnet      # birdnet | mock
  min_confidence: 0.35
  use_location_filter: true
detect:
  announce_threshold: 0.60
  min_consecutive: 2
  cooldown_s: 120
llm:
  backend: ollama       # ollama | mock
  model: qwen2.5:3b
  host: http://127.0.0.1:11434
tts:
  enabled: true
  voice: en_US-lessac-medium
pocket_mode:
  speak_only_new_species: true
  chime_on_rare: true
privacy:
  save_clips: false     # raw audio is never stored unless true
server:
  host: 127.0.0.1
  port: 8000

7. Database schema

Put this in storage/schema.sql. species.sqlite is read-only at runtime; walks.sqlite is the log.

-- species.sqlite
CREATE TABLE species (
  scientific_name TEXT PRIMARY KEY,
  common_name     TEXT NOT NULL,
  family          TEXT,
  habitat         TEXT,
  size_note       TEXT,
  call_note       TEXT,
  rarity          TEXT          -- common | uncommon | rare
);

-- walks.sqlite
CREATE TABLE walks (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  started_at TEXT NOT NULL, ended_at TEXT,
  lat REAL, lon REAL, journal TEXT
);
CREATE TABLE sightings (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  walk_id INTEGER NOT NULL REFERENCES walks(id),
  scientific_name TEXT NOT NULL, common_name TEXT NOT NULL,
  confidence REAL NOT NULL, t_offset_s REAL NOT NULL
);
CREATE INDEX idx_sightings_walk ON sightings(walk_id);

seed_species_db.py builds species.sqlite from the BirdNET label list (scientific and common names) and merges data/species_facts.json where available. Ship 20 to 30 curated entries in that JSON for common species.

CLI (python -m trailear ...): walk (live mic, pocket mode), file PATH.wav (offline test), serve (API and PWA), journal WALK_ID, devices, species SEARCH.

PWA requirements

  • Three views: live feed, life list, walk summary with journal text.
  • Service worker caches all static assets so the page loads with Wi-Fi off.
  • Big start and stop button, high contrast, usable in sunlight.

9. Pocket mode (the touch-grass feature)

  • python -m trailear walk --pocket starts capture with no UI required.
  • Speaks "Walk started", then each newly announced species once. Optional short chime when a species is marked rare.
  • Stops cleanly on Ctrl+C or a configurable "stop" keypress, speaks the count of species heard, and saves the walk.
  • Journal generation happens after stop and can run later with journal WALK_ID.

11. Windows setup script

scripts/setup_windows.ps1 must, in order, with clear status messages and non-zero exit on hard failure:

  1. Check Python 3.11 is available; create .venv and activate it.
  2. pip install -e .[dev].
  3. Check ollama is on PATH; if present, run ollama pull qwen2.5:3b; if not, print the install link and continue using the mock LLM.
  4. Run fetch_models.py to download the BirdNET model and the Piper voice into models/.
  5. Run seed_species_db.py.
  6. Run pytest -q and print the result.
  7. Print the next commands: python -m trailear file data/samples/sample.wav and python -m trailear serve.

scripts/demo_offline.ps1 runs a sample WAV through the whole pipeline and prints the journal. This is the script to screen-record in airplane mode.

12. Tests

  • test_classifier.py: Mock classifier returns sorted detections; BirdNET test skipped if the model is missing.
  • test_manager.py: threshold, cooldown and consecutive-hit logic with synthetic detections.
  • test_storage.py: walk and sighting insert, life-list query, in-memory SQLite.
  • test_journal_prompt.py: prompt contains only provided species; grounding check rejects an invented species and falls back to the template.
  • test_api.py: FastAPI test client covers start, stop, walks list and health.
